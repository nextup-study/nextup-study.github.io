# Next Up (beta)

A small web app that tells you which project to work on next. You list your projects, what you have to hand in, rough hours and deadlines, and it ranks them by how much time you have left once your class timetable is counted.

Set up for INDA Year 4, Term 1 (2026): tap **Load Term 1 schedule** on first open.

- Everything you add is saved in your own browser (localStorage). Nothing is sent anywhere.
- Clearing browser data or switching devices starts you from scratch.

Built as a prototype with Claude.
